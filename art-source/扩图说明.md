# 把小屋扩成整间房

现在的插画只是房间的 1/4。新房间是 480×270 像素，现在的画面原样放在正中间（从 x=120, y=67 开始），四周按设计稿第 5.2 节的原始线框补全。

## 文件

| 文件 | 用途 |
|------|------|
| `outpaint-canvas.png` | 扩图画布：原图在正中，四周留白。**交给生图工具补全的就是这张** |
| `outpaint-layout.png` | 构图参考：四周每个位置放什么（虚线框 = 留空，以后放照片摆件） |
| `room_original.png` | 原图 |

## 步骤

1. 打开能生成 / 编辑图片的工具（AI Studio 里选 Gemini 的图像模型，或者你生成原图的那个工具）
2. 上传两张图：**第一张** `outpaint-canvas.png`，**第二张** `outpaint-layout.png`
3. 粘贴下面的提示词，生成 3–4 张
4. 挑一张：四周物件齐全、像素颗粒大小和中间一致、边缘和中间接得上。中间画面被改了一点也没关系，后面的脚本会把原图贴回去
5. 把选中的图保存到这个文件夹，然后运行（在 pixel-room 目录下）：
   ```bash
   python tools/merge_outpaint.py art-source/选中的图.png
   ```
   会生成 `prototype/assets/bg/room-full.png`，并告诉你中间对齐得怎么样
6. 接下来改 `prototype/data/scene.json`：分辨率改成 480×270，原有坐标整体加 (120, 67)，给新物件加热区和照片槽位

## 提示词（英文，整段复制）

```
Fill in the white area around the picture to complete the WHOLE room, as one wide 16:9 pixel-art scene.

Rules:
1. Do NOT change the picture in the center at all: same boy, chair, laptop, cat, lamp, mug, window and bookshelf, same position and same size. Only paint the white area around it.
2. Continue everything that touches the edges: the same window continues upward, the same bookshelf continues upward, the same desk continues to the left and right, and the front of the desk (with drawers) shows below it.
3. Use the second image ONLY as a guide for where things go. Do not copy its boxes, lines, colors or any text.
4. Add these, in exactly the same pixel-art style, the same dusk lighting and the same warm plum and sunset colors:
   - top-left: a hanging pothos plant, three small empty picture frames on the wall
   - left wall: a tall bookshelf with three shelves, a few books, one small trophy, and clear EMPTY gaps on every shelf
   - left end of the desk: a record player, a few sticky notes on the wall, one empty spot
   - top-right: a round wall clock next to the bookshelf, a wall calendar
   - right wall: a cork board with a few pins and lots of EMPTY space, a framed certificate, a small poster
   - right end of the desk: a phone lying flat and two empty spots
   - floor: a wooden storage chest at the bottom-left, a rug
   - a string of small fairy lights along the ceiling
5. Leave the EMPTY spots really empty. Photos will be placed there later.
6. Crisp hard pixels with the same pixel size as the center picture. No blur, no text, no letters, no UI, no watermark, no extra people.
```

## 生成不理想时

| 现象 | 处理 |
|------|------|
| 把中间的人也重画了 | 没关系，脚本会贴回原图；只要四周接得上就行 |
| 输出不是 16:9 | 补一句 `Output must be 16:9, same size as the first image.` |
| 四周画成了另一种画风 / 颗粒更细 | 补一句 `Match the chunky pixel size of the center picture exactly.` |
| 照抄了参考图的方框或文字 | 只上传第一张，把第二张的内容改成文字描述（提示词第 4 条已经写了位置） |
| 一直扩不好 | 改用「缩小视角」：只上传 `room_original.png`，提示词第一句换成 `Zoom out from this picture to show the whole room; the current picture becomes the center quarter.` |
